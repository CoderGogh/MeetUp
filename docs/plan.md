# 어디가? 기초 기획안

컨셉(`docs/concept.md`)을 6주 1인 개발 일정과 브랜치·PR 단위로 쪼갠 문서.

## 전제

- 비상업 개인 프로젝트. 외부 API는 무료 쿼터 안에서만 쓴다
- 웹 MVP 1차만 다룬다. 앱·결제·광고·로그인 없음
- 대중교통 소요시간은 공공데이터 지하철 그래프로 계산한다. ODsay는 무료 한도가 월 30건이라 표본 검증에만 쓴다. 런타임 외부 호출은 주소 지오코딩뿐

## 목표

| 구분 | 목표 | 기준 |
|---|---|---|
| 서비스 | 로그인 없이 3분 안에 출발지 입력 완료 | 링크 클릭 → 입력 완료 |
| 서비스 | 누가 얼마나 이동하는지 한 화면에서 비교 | 매트릭스 1장 |
| 서비스 | 확정 결과가 각자의 길안내로 이어짐 | 지도 앱 연결 |
| 기술 | 10인 동시 투표 100회 반복 집계 오차 0건 | 부하 테스트 |
| 기술 | 후보지 산출 1초 이내 (10인, p95) | 부하 테스트 |
| 기술 | 새로고침 후 단계·입력값 100% 복원 | 강제 단절 테스트 |

## 구성 요약

| 영역 | 선택 | 이유 |
|---|---|---|
| 백엔드 | Java 17 · Spring Boot 3.x | |
| 기준 데이터 | PostgreSQL + PostGIS | 역·후보지·이동시간 행렬, 최근접 역 탐색 |
| 방 상태 | Redis | TTL 자동 만료, 원자 연산 투표 집계 |
| 실시간 | SSE (`SseEmitter`) | 서버→클라이언트 단방향 전파면 충분 |
| 적재 | 지하철 그래프 최단 경로 계산 + ODsay 표본 검증 | ODsay 무료 월 30건. 9,000조합을 API로 못 채움 |
| 프론트 | 모바일 우선 웹 + 카카오맵 JS SDK | |

결정 보류 두 가지(투표 집계 방식, 다중 인스턴스 전파)는 구현 후 측정해서 정한다.

## 단계별 범위

| 단계 | 범위 |
|---|---|
| Phase 1 (MVP) | 방 · 출발지 · 후보지 산출 · 동시 투표 · 확정 · 길안내 |
| Phase 2 | 테마별 주변 장소 추천 · 결과 이미지 · 동점 추첨 연출 |
| Phase 3 | 수도권 확대 · 지도 시각 효과 · 캘린더 등록 |

MVP 적재 범위는 서울 주요 노선 304역 × 후보지 30곳 = 9,120조합. 그래프 계산이라 몇 초에 끝난다 (`docs/loader.md`).

## 작업 흐름

1. 이슈 등록 (FR·NFR 번호 연결)
2. `main`에서 브랜치 생성
3. 잘게 커밋 → push
4. PR 템플릿 작성 → CI 통과 → merge commit 병합 → 브랜치 삭제
5. 병합 후 진행 상황을 이슈에 체크

`main`은 보호 브랜치다. 직접 push, force push 모두 막는다.

## 커밋 단위

이력이 곧 설계 과정의 기록이 되도록 잘게 쌓는다.

- 한 줄 `type: 설명`, 변경 1,200자 이하
- 쪼개는 기준: 테이블 하나, 클래스 골격, 메서드 하나, 예외 처리 하나, 테스트 케이스 하나, 문서 절 하나
- 실패 → 수정 순서도 그대로 남긴다 (예: 락 없는 버전의 실패 테스트를 먼저 커밋)
- 측정 수치는 원본 로그와 같은 커밋 또는 바로 다음 커밋에

### 예시 — `feat/room-state-machine`

```
feat: 방 상태 enum
feat: 상태 전이 허용 목록
feat: 전이 단일 진입점 골격
feat: 허용 외 전이 409·현재 상태 반환
feat: 방장 권한 검사
feat: 전이 성공 시 roomRev 증가 (원자 처리)
feat: state.changed 이벤트 발행
test: 정방향 전이
test: 역방향·건너뛰기 전이 거부
test: 팀원 전이 요청 거부
test: 미입력자 남은 상태 산출 요청 거부
docs: 상태 전이표
```

브랜치 하나에 10~20커밋, 6주 전체로 300커밋 이상을 목표로 한다.

## 주요 리스크

| 리스크 | 대응 |
|---|---|
| 적재 기간이 일정을 잡아먹음 | 1주차에 9,000조합으로 시작, 백그라운드 적재 |
| 동시성 문제가 재현 안 됨 | 락 없는 버전 실패 사례를 먼저 남김 |
| 범위가 불어남 | 하지 않는 것 목록 고정, 새 아이디어는 Phase 2로 |
| 무료 쿼터 소진 | 런타임 경로 호출 제거, 지오코딩 동일 주소 캐시 |
| 키 유출 | `.env` 분리, 커밋 전 비밀값 검사 |

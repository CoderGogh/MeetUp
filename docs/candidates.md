# 후보지 선정

후보지 품질이 결과 품질이다. 전체 역을 후보로 두면 상권 없는 역이 1위로 나온다. 그래서 자동 수집하지 않고 기준을 세워 30곳을 직접 골랐다.

## 기준

**넣는 역**

1. 환승역이거나 승하차 인원이 많은 역
2. 역에서 걸어서 10분 안에 식당·카페 상권이 있는 곳
3. 노선 분포. 한 노선이 절반을 넘지 않게 (2호선은 순환 간선이라 상한까지 허용)
4. 권역 균형. 네 권역 모두 5곳 이상

**빼는 역**

- 갈아타기만 하는 역
- 역 주변에 머물 곳이 없는 역
- 이미 고른 후보와 한두 정거장 거리라 결과가 겹치는 역

## 권역

| 권역 | 코드 | 구 |
|---|---|---|
| 강남 | `GANGNAM` | 강남·서초·동작·관악 |
| 강북 | `GANGBUK` | 종로·중구·용산·성북·노원·도봉 |
| 서부 | `WEST` | 마포·서대문·은평·영등포·구로·강서·양천 |
| 동부 | `EAST` | 성동·광진·동대문·송파·강동 |

## 태그 규칙

외부 API에는 "조용함"·"분위기" 같은 값이 없다. 테마 태그는 아래 규칙으로 직접 붙인다. 규칙은 테스트(`CandidateSeedTest`)로 묶어 둔다.

| 태그 | 붙이는 조건 | 막는 조합 |
|---|---|---|
| `MEETING` 회의 | 환승역, 과밀 상권 회피 | 단일 노선 역 |
| `TALK` 진지한 대화 | 번화가 회피 | 대형 상권 |
| `CASUAL` 가볍게 | 상권 밀집 | 역세권 소규모 |
| `DATE` 데이트 | 역세권 + 상권 밀집 | 역세권 소규모 |
| `INDOOR` 실내 | 역에서 밖에 안 나가고 상권 연결 | 지하·실내 연결 없음 |

지하 연결(`underground`)은 지하상가·복합몰 직결처럼 비를 안 맞고 역에서 상권으로 가는 경우만 참으로 둔다.
